# АПКС — Лабораторна робота № 1

**Проєктування AI-агента для автоматизації розробки та CI/CD**

| Поле | Значення |
|------|----------|
| Студент | Бартошко Олександр Ігорович |
| Група | КІ-408 |
| Варіант | 1 — C++ / CMake / GoogleTest + CTest |

Репозиторій містить AI-агента (Claude Code), який генерує, складає, тестує та
перевіряє кросплатформний проєкт `Hello World` і налаштовує GitHub Actions для
Windows, Linux та macOS.

Структура гілок:

- `master` — стабільна гілка;
- `develop` — AI-агент з інструкціями (manifest, skills, commands, документація);
- `feature/hello-world-cpp` — результат запуску агента: вихідний код, тести, CI.
